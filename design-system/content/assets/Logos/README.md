# Logos

The Birdbrain mark as shipped in the repository: a dark bird with a cyan eye and an indigo node graph on its wing, on an indigo rounded square. Raster only; no SVG mark exists.

- `birdbrain-logo-256.png` (256 × 256, `src/renderer/assets/logo.png`): the in-app mark on the dashboard hero, onboarding and the About panel. Use at 24 to 128px.
- `birdbrain-icon-1024.png` (1024 × 1024, `resources/icon.png`): the application icon source that the 16 to 512px `resources/icons/` set is cut from.

Place the mark on `color-canvas` or `color-surface` with at least 8px clear space; it carries its own indigo ground, so never add a second tint behind it. The wordmark is plain Inter Variable at 600, never a styled logotype.
