> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add end-to-end tests using Playwright + Electron that verify core CRUD flows (cases, tags) and app lifecycle.

**Architecture:** Playwright's `_electron.launch()` connects to the built Electron app. Each test gets a fresh temp directory (isolated SQLite DB + storage). A shared fixture handles app launch/teardown. One small code change in `src/main/index.ts` allows tests to override the user data path via env var.

**Tech Stack:** Playwright Test, Electron 33, electron-vite build output at `./out/main/index.js`

### Task 4: Create the Electron app fixture

**Files:**
- Create: `e2e/fixtures/electronApp.ts`

**Step 1: Create the shared test fixture**

Create `e2e/fixtures/electronApp.ts`:

```ts
import { test as base, _electron, type ElectronApplication, type Page } from '@playwright/test'
import { mkdtemp, rm } from 'fs/promises'
import { join } from 'path'
import { tmpdir } from 'os'

type ElectronFixtures = {
  electronApp: ElectronApplication
  page: Page
}

export const test = base.extend<ElectronFixtures>({
  electronApp: async ({}, use) => {
    const tempDir = await mkdtemp(join(tmpdir(), 'birdbrain-test-'))

    const app = await _electron.launch({
      args: [join(__dirname, '../../out/main/index.js')],
      env: {
        ...process.env,
        BIRDBRAIN_USER_DATA: tempDir
      }
    })

    await use(app)

    await app.close()
    await rm(tempDir, { recursive: true, force: true })
  },

  page: async ({ electronApp }, use) => {
    const page = await electronApp.firstWindow()
    await page.waitForLoadState('domcontentloaded')
    await use(page)
  }
})

export { expect } from '@playwright/test'
```

How this works:
- `electronApp` fixture: Creates a temp dir, launches Electron with `BIRDBRAIN_USER_DATA` pointing to it. After the test, closes app and deletes the temp dir.
- `page` fixture: Waits for the first BrowserWindow's renderer to be ready, then yields the `Page` object for DOM interaction.
- Tests import `test` and `expect` from this file instead of directly from `@playwright/test`.

**Step 2: Commit**

import { test, expect } from './fixtures/electronApp'

test.describe('Tags CRUD', () => {
  test('can create a new tag', async ({ page }) => {
    // Open tag manager
    await page.click('[data-testid="manage-tags-btn"]')

    // Type tag name
    await page.fill('[data-testid="tag-name-input"]', 'Evidence')

    // Click add

    // Verify tag appears in the manager's list

    // Close manager
    await page.click('[data-testid="tag-done-btn"]')

    // Verify tag badge appears in sidebar
    await expect(page.locator('text=Evidence')).toBeVisible()
  })

  test('can delete a tag', async ({ page }) => {
    // Open tag manager
    await page.click('[data-testid="manage-tags-btn"]')

    // Create a tag first
    await page.fill('[data-testid="tag-name-input"]', 'Temporary')
    await page.click('[data-testid="tag-add-btn"]')

    // Verify removed from manager list

    // Verify both exist

    await expect(page.locator('[data-testid="tag-manager"] >> text=Tag Two')).toBeVisible()
