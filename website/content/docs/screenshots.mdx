## Regenerating this tour

The series comes from a Playwright script against the seeded demo case. Rebuild the app, then run from the repository root:

```bash
README_SHOTS=1 npx playwright test e2e/readme-screenshots.spec.ts
```

Output lands in `test-results/readme/` with light and dark variants of every shot. The light variants are referenced directly; manually copy the dark variants (e.g., `screenshot-case-dark.png`) into `website/content/images/` to update the dark-mode versions on the site.
