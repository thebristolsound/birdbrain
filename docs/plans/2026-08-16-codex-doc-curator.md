## Local end-to-end run (2026-08-16)

Window `b686cb5..523b9b8` (7 days, 97 merges, 41 PRs, 2.2 MB diff), scratch worktree.

- Author pass 1: 3 sections, all inside budget, honest 4-item "not attempted". Two real errors:
  signing key claimed to report `not-set` (`src/shared/types.ts:268` says never), and enum names
  quoted where Diagnostics renders "Protected/Unprotected".
- Reviewer with in-prompt truncated diff: **approved, empty reasons** — the evidence was past the
  truncation point. Redesigned: reviewer gets read-only tools on the checkout, must list what it
  verified. Re-run: **rejected both errors with file:line**, cost $4.60 vs $5.72.
- Author pass 2 (reasons fed back): fixed both, but deleted a roadmap item wholesale (only half
  shipped) and restyled untouched sentences in §4.4. Reviewer **rejected on scope**, verified the
  rest for the record. Second reject → discard. Correct outcome: no PR with an overstated claim.
- Reviewer cost ≈ $4–6 per pass at 3 turns; author cost not measured (ChatGPT login locally).
- Observation, not a change: pass 2 was one small fix from approvable. If discards are common,
  raising the retry cap to 2 is the lever; ADR-0012 fixes it at 1 for now.
